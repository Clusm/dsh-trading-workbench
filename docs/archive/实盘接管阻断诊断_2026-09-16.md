## 2. 界面切不了实盘 —— 根因

### 2.1 现场证据

```
GET http://127.0.0.1:8000/api/mode
{"current":"demo","profile":"demo","mode_locked":true,"pending":null,
 "available":{"demo":{"label":"模拟盘","configured":true},
              "live":{"label":"实盘","configured":true}}}
```

`mode_locked: true`。三处代码共同构成这道锁：

| 位置 | 行为 |
|---|---|
| `src/dashboard/templates/index.html:13` | `<select id="mode-select" ... {{ 'disabled' if profile else '' }}>` —— profile 非空时**下拉框直接禁用** |
| `src/dashboard/templates/index.html:22` | 渲染「独立账户控制台 · {{ profile }}」，即页面上那行灰字 |
| `src/dashboard/app.py:2130-2133` | `POST /api/mode` 在 `settings.profile_name is not None` 时抛 409「独立控制台已绑定账户模式，请打开对应的 Demo 或实盘控制台」 |

### 2.2 为什么会这样

`696fa6b`（方案B 双进程双账本）把「模式」从运行时可切换项改成了**启动时冻结的 profile**：

```python
# src/exchange/factory.py:40
mode = settings.profile_name or raw_mode or str(cfg.get("default_mode", "demo")).strip().lower()
```

`profile_name` 优先级高于 `EXECUTION_MODE`。也就是说：

- 起 `--profile demo` → Broker 必然是 demo，`data/` 账本，端口 8000
- 起 `--profile live` → Broker 必然是 live，`data/live/` 账本，端口 8001

两个实例互不覆写、互不阻断（除限流状态文件有意共享）。**界面内切换会破坏这个不变量**，
所以被显式禁掉。

### 2.3 正确做法

不是去解锁下拉框，而是**启动第二个控制台**：

```powershell
.venv\Scripts\python.exe scripts\start_web_detached.py --profile live   # → 127.0.0.1:8001
```

端口唯一来源为 `src/core/config_loader.py:56-58`（live=8001 / demo=8000）。

## 5. 剩余阻断清单

### 5.1 网络出口（最容易踩，必须先解决）

`.env:31` 的 `MTA_NO_PROXY=1` 会让 `src/core/net_env.py` 写入 `NO_PROXY=*` 并清空代理变量，
即**强制直连**。实测直连已失效：

| 出口 | fapi.binance.com（主网） | demo-fapi.binance.com |
|---|---|---|
| 直连 | ConnectTimeout（10s） | ConnectTimeout（10s） |
| 代理 10808 | **200** | **200** |

用程序自身代码路径（`apply_proxy_env()` + httpx）复现，结论一致：`MTA_NO_PROXY=1` → 双双超时；
`MTA_NO_PROXY=0` → 双双 200。

**为什么 demo 现在看起来正常**：`scripts/start_web_detached.py:67-91` 的 `build_env()`
在 `--proxy` 下会显式写 `MTA_NO_PROXY=0` 并注入 `HTTP(S)_PROXY`，覆盖 `.env` 的直连设定。
手工执行 `python scripts/xxx.py` 不走这条路径，就会被 `.env` 拖成直连 —— 这正是本次预检
第一次报 `ConnectTimeout` 的原因。

> 附带风险：`.env` 注释记录 2026-09-05 直连「6/6 全通」，现已被推翻。若长期走代理，
> 代理进程成为单点故障（注释本身也承认「代理软件退出会全站 10061」）。
