## 一、P0 — 上实盘前必须修复

### P0-1 来源台账 ledger 并发丢更新
- **位置**：`src/exchange/binance_futures.py:122-176, 505-581, 1057-1135`
- **问题**：`_load_ledger/_save_ledger` 无锁。dashboard 线程（紧急平仓、资金重置）与交易循环（追加限价挂单、平仓收口）并发"读→改→写"。典型场景：`close_all` 平仓耗时数秒期间，快循环追加了一条 LIMIT 挂单并保存，`close_all` 结尾用旧快照覆盖 → 该挂单从台账消失：成交后无人补 SL/TP、无来源记录、永不到期。且两个 writer 共用同一 `.tmp` 路径，可写坏文件。
- **修法**：broker 加一把 `RLock`，所有 ledger 的 load-modify-save 全程持锁；tmp 文件名加进程/线程区分。

### P0-2 被收养（adopt）的无主仓位永远不挂止损，裸仓运行
- **位置**：`binance_futures.py:894-898, 1169-1194`
- **问题**：`_resync_protection` 在 `sl=None, tp=None` 时直接判定"无需保护"返回 True。`sync_positions` 把"交易所有、台账没有"的仓位 adopt 为 ai legacy 后，该仓位永远没有保护单。触发场景：下单 POST 超时但交易所已成交（响应丢失）、用户在交易所网页手动开仓。与"新开仓必须带初始保护"的硬规则直接矛盾。
- **修法**：adopt legacy 时立即按入场价 ± 固定百分比（或 ATR）兜底挂 SL/TP，并发 critical 告警；禁止无保护仓位静默存活。

### P0-3 Dashboard 写操作接口零鉴权，可被本地 CSRF 打穿
- **位置**：`src/dashboard/app.py:1306-1312`（`/api/control`）、`1347-1395`（`/api/capital/reset`）、`/api/mode`
- **问题**：`POST /api/control {"state":"emergency"}` 会真实平掉全部仓位，但无任何 token；FastAPI 的 `payload: dict` 不校验 Content-Type——浏览器开着控制台时，任意恶意网页可用 `fetch(mode:'no-cors', text/plain)` 对 `127.0.0.1:8000` 发起本地 CSRF 触发紧急平仓/资金重置/切模式。
- **修法**：① 所有 POST 接口要求随机 token（启动时打印到控制台，前端注入 header）；② 服务端强制校验 `Content-Type: application/json`；③ emergency 增加 confirm 二次确认参数。
- **已确认良好**：host 默认绑 `127.0.0.1`，未发现 `0.0.0.0`；`.env` 未入 git、历史无提交。

## 三、P2 — 健壮性/质量（择机处理）

- SQLite 未设 `PRAGMA busy_timeout=5000`；诊断脚本跨进程写库会撞锁。
- `recvWindow=5000` 无服务器时间校准：代理环境时钟漂移 >5s 全部签名请求 -1021。建议启动时用 `/fapi/v1/time` 校准 offset。
- `capital_state.json` 读写无锁（ledger/channel 都有锁，唯独它没有）。
- paper broker 无手续费/滑点/资金费率/部分成交/minQty，**paper 模式的验证结论偏乐观，只应采信 demo 模式的结论**。
- 保证金校验用 session_equity 而非交易所 `availableBalance`，多仓并持时可能 -2019 被拒。
- `state` 属性每次新建线程池 + 重试 3×0.5s，dashboard 冷启动最坏阻塞 40s+。
- `config/settings.yaml:86` 硬编码绝对路径 `C:/Users/Tao/Desktop/ai-trader/...`，换机器必坏。
- `requirements.txt`：缺 `langchain-core`（被直接 import）、`pydantic-settings` 未用可删；无版本锁定，上线前 `pip freeze`。
- `/api/status` 缓存击穿（锁间隙重复计算）；live 模式切换仅校验 key 存在，无二次确认。
- 首页 1s 轮询 `/api/prices`：推送降级时建议放宽到 3s。
