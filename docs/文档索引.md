## 脚本入口索引

| 类别 | 入口 | 说明 |
|---|---|---|
| 启动 | `scripts/run_web.py` | 统一前台生命周期入口；必须显式指定 live profile |
| 临时分离启动 | `scripts/start_web_detached.py` | 当前过渡方式，不等同于无人值守托管 |
| 质量门禁 | `scripts/check_quality.py` | Ruff、编译、风险锁、依赖锁和密钥扫描 |
| 离线回归 | `scripts/run_offline_regression.py` | 默认禁网，不读取真实凭据或运行账本 |
| 发布评估 | `scripts/report_release_readiness.py` | 7 天、200 候选、30 笔闭合交易等严格门槛 |
| Demo 验收 | `scripts/report_demo_acceptance.py` | Demo 候选、闭合归因交易和观察天数 |
| 实盘预检 | `scripts/preflight_live_account.py` | 只读核对账户模式、仓位、订单与保证金 |
| 健康守望 | `scripts/health_watch.py` | 不构造 TradingService 的只读监控 |
| LLM 验证 | `scripts/verify_llm_provider.py` | 显式在线协议检查；不会读取账户或下单 |
| 恢复 | `scripts/create_recovery_bundle.py` / `restore_recovery_bundle.py` | 停写一致性恢复包与只写新目录恢复 |

命名约定：`smoke_*` 是隔离冒烟；`probe_*` 和 `verify_*_live` 可能联网；`diag_*` 默认只读；
`cleanup_*`、`repair_*` 会改变状态，执行前必须先预览目标并准备后置核验。
