## 0. 本文是什么、不是什么

**是**：一份可执行的**接口映射**——把"哪些核心模块值得拆、按什么边界拆、拆出来的公开面
怎么定、哪些东西必须原样不动"写成后续实施者（和审查者）能照做的清单，并为每个阶段
配一条**可实跑的出口命令**。

**不是**：重构本身。U11 是 P2 后置任务，卡面明确"**逐模块转移所有权后实施**"，且
"**重构不混风控或策略行为修改**"。因此：

> **本文不新建、不移动、不修改任何 `src/` 文件。** 一切拆分以"提案"形式给出；
> 真的动手需要 I 先按维护规范 §11.1 把目标子模块**登记进所有权表并分派独立审查**，
> 且一次只动一个模块（见 §6 阶段化）。

把话说破：**这份文档的价值在"诚实与可执行"，不在"拆得漂亮"**。任何一份写着
"全部拆完"却绕开下面 §2 那些已被独立复验的约束的方案，都是废纸。所以本文篇幅的
一半用来做一件事——**证明"不拆"也是结论**。

### V1 · 公开面逐字不变（P1/P2/P3 出口，**核心断言**）

```bash
    if alls is not None:
```

#### C1 · 口径说明（R1 未言明，此处写死）

| 模块 | `__all__` | `dir()` | 差额来源 |

| `core.decision_trace` | **61** | **86** | 25 = 偶然导入（`Any`/`Callable`/`ctypes`/`json`/`math`/`os`/`time`/`contextmanager`/`dataclass`/`field`/`StrEnum`/`Path`/`Sequence`/`Iterable`/`Iterator`/`Mapping`/`annotations`…）+ 契约透传（`DecisionCounters`/`DecisionTraceSpan`/`SpanValidationError`）+ `DEADLINE_TOLERANCE_MS` |

1. **`__all__` 口径（主判据）**：`from core.decision_trace import *` 的语义由此定义。

4. **漏报边界（必须知道）**：`__all__` 以 `_` 开头，被 `dir()` 过滤掉，

### V1b · 映射覆盖率自检（**新增，专治 R1 的阻塞 1**）

R1 的 V1 有一个**反向盲区**：它只回答"拆分后名集合变没变"，

```bash
PYTHONUTF8=1 PYTHONPATH=src python - <<'PY'

from pathlib import Path
doc = Path("docs/重构接口映射.md").read_text(encoding="utf-8")
mentioned = set()
for tok in re.findall(r"`([^`\n]+)`", doc):
    mentioned |= set(re.findall(r"[A-Za-z_]\w*", tok))
bad = 0
for mod, src in [("core.decision_trace", "src/core/decision_trace.py"),
                 ("core.strategy_funnel", "src/core/strategy_funnel.py")]:
    tree = ast.parse(Path(src).read_text(encoding="utf-8")); defs = {}
    for n in tree.body:
        names = ((n.name,) if isinstance(n, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef))
                 else tuple(t.id for t in n.targets if isinstance(t, ast.Name)) if isinstance(n, ast.Assign)
                 else ((n.target.id,) if isinstance(n, ast.AnnAssign) and isinstance(n.target, ast.Name) else ()))
        for x in names:
            if not x.startswith("_"): defs[x] = n.lineno
    miss = sorted(x for x in defs if x not in mentioned)
    print(f"{mod}: 顶层公开定义 {len(defs)}，覆盖率 {100*(len(defs)-len(miss))/len(defs):.1f}%，漏项 {len(miss)}")
    for x in miss: print(f"   MISSING {x}  ({src}:{defs[x]})")
    bad += bool(miss)
print("V1B " + ("OK 映射覆盖完整" if not bad else f"FAIL {bad} 个模块漏项"))
sys.exit(1 if bad else 0)
```
